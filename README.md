# Excel Sales Analysis

## Project Overview

This project analyzes sales data using Microsoft Excel.

## Objectives

- Use lookup functions to retrieve product information.
- Calculate revenue, profit, and profit margin.
- Analyze sales performance by region and category.
- Create KPIs and a regional sales summary.

## Key Analysis

- Total Revenue
- Total Profit
- Average Revenue per Order
- Number of Orders
- Technology Revenue
- Furniture Revenue
- Regional Revenue and Profit

## Tools Used

- Microsoft Excel
- XLOOKUP
- SUM
- AVERAGE
- SUMIF
- COUNTIF
- IF
